# Issue Tracker

## Location

Issues for this repository live as local Markdown files under `.scratch/<feature>/`.

## Workflow

- Create one directory per feature, bug, or investigation.
- Keep the issue description, decisions, and validation notes in Markdown files inside that directory.
- Use the repository triage labels from `triage-labels.md` in issue frontmatter or status sections when applicable.
- No GitHub or GitLab CLI is required for this workflow.

## Pull Requests

Pull requests are not part of the local issue-tracker queue by default.
