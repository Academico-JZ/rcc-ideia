# Triage Labels

Use these canonical labels for issue triage:

| Role                   | Label             |
| ---------------------- | ----------------- |
| Needs triage           | `needs-triage`    |
| Needs more information | `needs-info`      |
| Ready for agent        | `ready-for-agent` |
| Ready for human        | `ready-for-human` |
| Won't fix              | `wontfix`         |
